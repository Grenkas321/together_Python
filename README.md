# Python Development Practice

Репозиторий с практическими заданиями по Python-разработке.

В рамках курса отрабатывались структура Python-пакетов, клиент-серверное взаимодействие, тестирование, документация, локализация, автоматизация сборки и работа с Git.

## Темы

- Python packages
- client-server applications
- unit testing
- mocks
- documentation generation
- localization with Babel
- automation with doit
- Git workflow

## Стек

- Python
